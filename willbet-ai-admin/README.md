# AIBot AI 助手运营后台一期

本地运行：

```sh
python3 server.py --port 4181
```

需要 Python 3 与 openpyxl。本地预览：http://127.0.0.1:4181/ 。原生 HTML / CSS / JavaScript，无前端构建步骤；Python 服务提供真实 Excel 模板和解析。每次修改后验证服务并在最终回复提供本地预览链接。

## 当前功能

- 五个模块：概览、Intent 管理、知识库、会话记录、基础配置。
- Intent 处理方式为知识回复或业务能力；回复形式使用固定九项枚举，支持多选、筛选和 Tag 展示。
- 一个知识回复 Intent 只关联一条有效 Knowledge；同一 Knowledge 可供多个 Intent 使用。选择器按 ID + 名称搜索、单选，确认仅进入草稿，保存后生效。未配置有效知识时不能启用或保存为知识回复。知识正文直接用于回复，不拼接或改写。
- 业务能力维护业务名称、说明及未开发 / 开发中 / 待发布 / 已发布状态。接入标记不开放运营修改；状态不等于技术接入。只有已接入、已发布且 Intent 启用时才具备服务条件。此项目仍是原型，没有真实业务接口。
- Knowledge 列表仅展示可用的纯知识。业务字段为 ID、模块、名称、回复正文；支持正文搜索、关联 Intent 数量及只读关联跳转。模块已明确时表单无需重复选择。
- Excel 从选定目录进入，模板仅有“知识名称”“回复正文”。上传后校验空字段、重复内容，预览后确认全部或仅有效行，自动生成 ID。
- 会话保留历史实际回复及知识 / 能力信息，提供全部、疑似未解决、无法回答、点踩、重复提问、转人工快捷筛选；支持关注 / 取消关注及运营备注，不新增问题 ID。
- 概览统计会话及巡检信号，趋势、热门 Intent、待关注会话和带时间 / 模块条件的会话跳转保留。正确登录引导、非业务回复、单纯转人工不自动计入疑似未解决。
- 基础配置包含名称、头像字符、欢迎语、推荐问题、四类兜底和转人工文案 / 客服入口。

## 历史兼容

存储键继续为 `willbet-admin-v1`。不清空旧浏览器数据，也不覆盖已有运营修改。ID 和原始历史问题记录保留；旧问题链接转到对应会话。

旧混合型知识保留原始数据，但排除出普通列表和关联选择；历史会话可查看只读历史记录。普通 Knowledge 不提供类型、Context 或来源配置。

迁移后的当前关联继续以 `intent.knowledge`（最多一个 ID）维护；原关联保存至 `legacyKnowledge`。若存在有效的旧主回复知识则优先沿用；无主回复且有多条关联时，当前关联为空，标记待配置，并保留原启用状态于 `legacyEnabled`。不自动选取知识，不再提供主 / 辅知识设置。迁移可重复执行，后续业务保存会持久化。

消息的历史回答、识别结果、实际知识列表不会随当前 Intent 编辑而改写。巡检读取历史回复信号，而非按今日配置反推历史是否失败。

## 纯知识问答库 V1 与富文本

2026-10-10 从 `WillBet AI 纯知识问答库 V1.0.xlsx` 的“知识问答”页导入 50 条有效记录：Sports 23、Casino 9、Wallet 12、Promotion 3、VIP 3。空行、“冲突待确认”和“来源核对”不导入。源正文逐字保留在 `knowledge-v1.js`；按业务模块追加导入，保持已有知识、Intent 关联和历史会话不变。首次打开时同时兼容已有本地浏览器数据，批次标记防止刷新重复导入；不会覆盖后续运营编辑。

知识正文使用富文本编辑器，可配置加粗、斜体、下划线、标题、列表、链接。`bodyHtml` 保存经过白名单清理的格式，`body` 保存对应纯文本，继续供搜索、校验和标准答案兼容使用。原有纯文本打开即可编辑，保存后保留格式；脚本、事件属性及危险链接不会保存。历史会话依然使用历史答案，不由当前知识重新生成。

每次修改完成后必须提供经验证可访问的本地预览链接，优先 `http://127.0.0.1:4181/`；保留 `server.py --port 4181` 服务以支持 Excel。此要求同时记录在项目根目录 `AGENTS.md`。
